# Claude-Projects

## Бикове и крави (C#, .NET 8)

Ти измисляш число от 4 различни цифри, а програмата го отгатва **до 7 опита включително**.
За всеки опит казваш колко са **биковете** (вярна цифра на вярно място) и **кравите** (вярна цифра на грешно място).

### Стартиране

```bash
dotnet run --project src/BullsAndCows.ConsoleApp                       # игра (числото може да започва с 0)
dotnet run --project src/BullsAndCows.ConsoleApp -- --no-leading-zero  # без водеща нула
dotnet run -c Release --project src/BullsAndCows.ConsoleApp -- --analyze  # проверка срещу всички числа
dotnet test
```

Режими на игра:
1. Държиш числото наум и сам въвеждаш бикове и крави (напр. `1 2`).
2. Въвеждаш числото и отговорите се смятат автоматично. Алгоритъмът и тогава не вижда числото - получава само бикове и крави.

Ако отговорите си противоречат (грешка при броенето), програмата го засича и казва, че няма такова число.

### Алгоритъм

1. **Пространство на решенията** - всички допустими числа: 10·9·8·7 = 5040 (или 9·9·8·7 = 4536 без водеща нула).
2. **Филтриране** - след всеки отговор остават само числата, които биха дали **същия** отговор на същия опит.
3. **Избор на опит - minimax (метод на Кнут)** - за всеки възможен опит (не само сред кандидатите)
   кандидатите се разделят на групи по отговора, който биха дали. Избира се опитът с **най-малка най-голяма група** -
   това гарантира най-добро поведение в най-лошия случай. При равенство: по-малка сума от квадратите
   на групите (по-малко очаквани оставащи кандидати), после опит, който сам е кандидат.
4. **Бърз отговор** - всяко число пази битова маска на цифрите си; общите цифри са `popcount(a & b)`,
   биковете са съвпаденията по позиция, а кравите са разликата.

### Доказателство, че 7 опита стигат

`--analyze` и тестът `Strategy_SolvesEverySecretWithinSevenAttempts` изиграват стратегията срещу **всяко** възможно число
(строи се дървото на решенията, затова отнема около 2-3 секунди):

| Опити | С водеща нула (5040) | Без водеща нула (4536) |
|------:|---------------------:|-----------------------:|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 43 | 49 |
| 4 | 526 | 540 |
| 5 | 2272 | 2297 |
| 6 | 2049 | 1606 |
| 7 | 147 | 40 |
| **Средно** | **5.341** | **5.228** |
| **Най-лошо** | **7** | **7** |

### Структура

```
src/BullsAndCows.Core         логика, без вход/изход
  Model/    Code, Feedback, FeedbackCalculator, CodeSpace, GameRules, FeedbackParser
  Solving/  IGuessStrategy, MinimaxGuessStrategy, CodeBreaker, StrategyAnalyzer
  Game/     IFeedbackProvider, SecretFeedbackProvider, GameRunner, GameResult
src/BullsAndCows.ConsoleApp   конзолен интерфейс
tests/BullsAndCows.Tests      xUnit тестове
```

Стратегията и източникът на отговори са зад интерфейси (`IGuessStrategy`, `IFeedbackProvider`),
така че лесно се сменят - например с друга стратегия или с уеб API вместо конзола.
